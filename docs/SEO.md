# Arquitectura SEO

Una página pilar cubre el conjunto de sinónimos de la categoría (`/grooming-vacuum/`). Las páginas de modelo y comparativas cubren entidades e intención de decisión. Las guías responden dudas informativas; las páginas “mejores para” requieren una necesidad distinta y evidencia suficiente. No crear páginas por cada variante lexical.

Solo páginas editoriales seleccionadas entran en sitemap. Finder, comparador y estados con parámetros no se indexan. Antes del lanzamiento: URL canónica real, auditoría de enlaces, fuentes, Search Console y comprobación de render móvil.
