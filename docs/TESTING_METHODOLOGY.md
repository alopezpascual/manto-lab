# Protocolo futuro de Manto Lab

No se han ejecutado pruebas propias. Al hacerlo, registrar modelo exacto, variante, lote, accesorios, fecha, lugar, manto, tarea, condiciones ambientales e instrumentos.

- Ruido: distancia y posición fija, nivel de aspiración registrado, ruido de fondo y varias repeticiones.
- Captura: masa inicial del pelo, masa recogida y eficiencia calculada, con control de pérdidas.
- Depósito: volumen útil al vaciar, separado del nominal declarado.
- Cortapelos: calidad de corte, tirones, temperatura, ergonomía y longitud de trabajo.
- Operación: tiempo de montaje, grooming, limpieza y alcance real de manguera más cable.
- Reacción canina: observación descriptiva con contexto; no convertirla en una puntuación generalizable.

Publicar resultados con protocolo, datos brutos y límites. Etiquetar por separado fabricante, investigación editorial, usuarios, medición propia y prueba práctica.
